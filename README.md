# Night Routes ZA

Night Routes is a peer-led South African chemsex harm-reduction, lived-experience and service-navigation resource.

The production site is a self-contained static application in `index.html`.

## Deployment

GitHub Pages deploys automatically from `main` using `.github/workflows/pages.yml`.

## Content note

The site discusses drug use, sex, overdose and mental health. It is intended as a harm-reduction and support-navigation resource.
